# AI Radar V1.2 — 阶段 1 交付与验收

## 本阶段交付
- 将首页从早期单文件 HTML 设计迁移为 React + TypeScript 组件结构。
- 建立统一深色数据工作台视觉样式，适配桌面和窄屏。
- 实现演示资讯的关键词搜索、中文/英文筛选、专题筛选、重要性/热度门槛筛选。
- 固定最新优先排序；不提供最早优先选项。
- 实现收藏筛选、重置筛选、资讯详情抽屉、专题快捷筛选。
- 导航中的其他页面明确标记为后续开发，不伪装成已完成模块。
- 新增架构全景图、前端组件图和产品经理说明。

## 当前限制
- 所有文章和统计均为演示数据，不代表真实行业信息。
- 没有连接 Worker、D1、生产 RSS 或登录系统。
- 收藏仅在当前页面会话有效。
- 尚未部署到 Cloudflare，不会修改当前 V1 线上站点。

## 验收清单
- [ ] 页面视觉与已确认的 V1.2 专业数据工作台方向一致。
- [ ] 桌面端筛选区、资讯流、右侧专题栏正常显示。
- [ ] 手机端布局可用，无横向溢出。
- [ ] 搜索、语言、专题、热度、重要性筛选可以组合使用。
- [ ] 排序始终为发布时间最新优先。
- [ ] 收藏、仅看收藏、重置筛选工作正常。
- [ ] 点击资讯标题打开详情抽屉，点击遮罩或关闭按钮可退出。
- [ ] 页面明确提示演示数据和未连接生产环境。
- [ ] 架构文档准确区分已实现、规划中、未实现。

## 下一阶段前置条件
验收首页后，再确定真实文章 API 的响应字段与分页方式；随后在 staging 环境接入 Worker 与 D1。管理员写入 API 必须等身份认证、授权、输入校验和审计日志准备完成后才开放。
